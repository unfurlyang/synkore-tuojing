# synkore·拓境 Windows App

1. 下载 Release 中的 Windows ZIP，完整解压到一个普通文件夹。
2. 双击 `synkore.exe`；首次入场有三秒粒子动画，之后进入课程工作室。
3. 「模型与设置」填写自己的 MiMo 密钥。它会使用当前 Windows 账户加密保存。请勿把自己的应用数据目录一起分享。
4. 不想配置模型时，可直接体验在线版：<https://synkore-tuojing.azuremoon15.chatgpt.site>。

三项功能：实时听课、教师画像、课后转译。录音需允许麦克风；可上传 WAV／MP3／M4A，或直接输入课程文字。内置教师方案标明来源；内置课程是原创导学示例。

下载包不含开发者密钥、配对令牌、Wi-Fi 密码和私人录音。若 Windows 对未签名应用显示发布者提示，请确认下载自本项目的 GitHub Release，并核对同一 Release 中的 SHA256 文件；当前版本未做商业代码签名。

连接实体 T5 开发板需两者处于同一局域网，按仓库 `docs/HARDWARE.md` 配置本机配对文件。无喇叭版本不发声。在线版不提供未经配对的公网硬件控制。
