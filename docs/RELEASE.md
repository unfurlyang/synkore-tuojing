# synkore·拓境 1.6.0

队名：闵交幼儿园。杨放负责前端、硬件与调试；梁佳钰负责后端。目标是拓展与探索课程程序的实现能力。

- 在线体验：https://synkore-tuojing.azuremoon15.chatgpt.site
- Windows App：下载 Windows-x64.zip，完整解压后运行 synkore.exe。交付包不含开发者密钥，首次配置自己的 MiMo；免配置体验请使用在线版。
- 核心功能：实时听课、教师画像、课后转译；包含可交互3D幽灵与温柔／灵动语音。
- 附真实功能录屏 MP4、示例合成课堂 WAV 与 SHA256SUMS.txt。MP4 为浏览器画面录屏，不含系统音轨。
- 源码：仓库内 cloud、desktop、firmware；启动步骤和第三方来源见 docs。固件源码不含私有配对令牌。

在线版音频每段最多5分钟，完整长课和T5硬件连接请用Windows版。教师方案为公开资料启发的设计建议，内置导学是原创短讲稿。

验证：桌面后端51项、云端6项通过；在线三项功能、真实音频识别与课后转译、会话隔离、播报文字核对和私人音频访问限制已实际验证。
