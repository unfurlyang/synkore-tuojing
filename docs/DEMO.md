# 约三分钟体验流程

入口：<https://synkore-tuojing.azuremoon15.chatgpt.site>。

1. **0:00–0:25**：观看粒子入场，拖动幽灵转身，体验摸摸、击掌、休息与语音切换。若浏览器首次阻止音频，点击一次互动按钮即可。
2. **0:25–1:05**：进入实时听课的「文字」输入，点击「试一段课堂文字」再处理；或允许麦克风录一句自己的课堂内容，停止后查看原文和整理结果。
3. **1:05–1:45**：进入教师画像，打开一数、宋浩或李永乐方案，查看规则和公开来源。也可切到「讲课文字」，输入至少20字的讲课样本并建立自己的画像。
4. **1:45–2:35**：选择教师，进入课后转化，选择高数等课程，预览原创导学，再点击「转译这份导学」。等待云端处理，查看与原文的对照。
5. **2:35–3:00**：导出笔记，说明 Windows App 支持完整课程音频与 T5 局域网终端。实体演示时在板上切教师／课程，电脑同步显示选择与处理结果。

网络与模型处理时间会影响总时长。未完成、额度不足或核对回退会真实提示，不会用预先写好的模型回答伪装成功。

题目截图要求演示视频**或**可运行链接；本仓库提供可运行链接和这份复现流程。若报名表另外强制要求录屏文件，应另附实际录屏，不能将入场角色动画当作功能演示视频。
