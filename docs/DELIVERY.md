# 交付物对照

对应比赛手册截图「5.2 交付物要求」。本项目提供可运行链接，不将角色入场视频冒充完整功能演示。

| 要求 | 本仓库交付 |
| --- | --- |
| 项目介绍：队名、成员、目标、功能 | 根 README：闵交幼儿园；杨放负责前端／硬件／调试，梁佳钰负责后端；目标及三项核心功能 |
| 代码仓库与环境依赖 | Web／Windows／Python／T5源码；npm锁文件、固定Python依赖、SDK实测提交 |
| 启动步骤与使用方法 | docs/RUNNING.md、WINDOWS.md、HARDWARE.md |
| 沿用组件来源 | THIRD_PARTY_NOTICES.md、docs/SOURCES.md、desktop/DESIGN.md |
| 演示视频或可运行链接 | 在线App及docs/DEMO.md；下载Release可运行Windows App |
| 比赛期间工作说明 | 本仓库仅提供作者确认的责任分工；更详细的团队信息与工作总览另行提交，不推断开发时间归属 |

截图中的物流仿真赛道有单独录屏要求；本仓库没有将该要求假定为本项目所属赛道，也没有声称满足未提供的额外赛道要求。

## 数据范围

公开交付物不含模型密钥、Wi-Fi密码、配对令牌、用户的录音、加密配置、个人笔记或完整闪存备份。Windows Release 不捆绑开发者模型配置。云端由服务端管理模型秘密，浏览器不接收密钥。

## 验证

- 桌面后端51项测试通过；共用前端原有9项相关流程测试通过。
- 云端6项测试覆盖音频格式、公式保护、会话隔离、跨域拒绝、错误不泄密及模型额度。
- Windows 1.6.0 已从交付源码构建，并实测启动、入场音效、双语音包和设置持久化。
- T5 2.2.0实机握手、Wi-Fi、麦克风上传、文字回传与选择同步通过；用户确认显示方向与触摸正常。
- 云端公开链接的实际验证结果以发布后的 docs/validation.json 为准。
